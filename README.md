# Fake Medicine Detection Using Blockchain

## Overview

Fake Medicine Detection Using Blockchain is a web-based system designed to identify counterfeit medicines through QR code verification. The project uses blockchain concepts to provide secure, transparent, and tamper-resistant medicine authentication.

## Features

* QR code based medicine verification
* Counterfeit medicine detection
* Tamper-resistant record tracking
* User-friendly web interface
* Pharmaceutical supply chain transparency

## Technologies Used

* HTML
* CSS
* JavaScript
* Blockchain Concepts
* QR Code Verification

## How It Works

1. A unique QR code is assigned to each medicine.
2. Users scan the QR code for verification.
3. The system checks the medicine record.
4. The result indicates whether the medicine is authentic or suspicious.
